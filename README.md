# LODR-042 LiveObjects Realtime Client API Improvements Demo

This repo is a types-only implementation of the improvements to the Ably LiveObjects Realtime Client API as proposed in: [LODR-042](https://ably.atlassian.net/wiki/spaces/LOB/pages/4235722804/LODR-042+WIP+Realtime+Client+API+Improvements).

- The implementation of the API typings is in `./src`.
- Some examples using the API can be found in `./examples`.

Please feel free to clone the repo and experiment with writing code using this API, and share any thoughts or feedback on the DR.
